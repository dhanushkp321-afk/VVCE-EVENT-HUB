Subject:
Requisition for Dedicated On-Premise Server & Domain Mapping for VVCE Events Hub
Executive Summary: The VVCE Events Hub is an institutional campus web application developed to centralize event approvals, club schedules, registration capacities, venue clash detection, and student attendance across 5,000+ students and 30+ clubs. To ensure 100% data sovereignty and eliminate all recurring third-party cloud costs, we request allocation of a dedicated on-premise server environment in the college data center.
1 Dedicated On-Premise Server Specifications
Component Recommended Technical Specification Operational Purpose & Rationale
Host System 1 Dedicated Machine / Virtual Machine (VM) Housed in the VVCE Server Room / Central Data Center.
Processor (CPU) 4 to 8 Cores (Intel Xeon / Core i7 or equivalent) Handles concurrent traffic spikes during college fest registrations.
RAM (Memory) 16 GB DDR4/DDR5 (Minimum: 8 GB) Supports in-memory caching, PostgreSQL queries, and WebSocket feeds.
Storage (Disk) 256 GB to 512 GB SSD / NVMe Stores event poster assets, certificates, and daily backup snapshots.
Operating System Ubuntu Server 24.04 LTS (64-bit) Enterprise-grade, virus-proof, open-source Linux environment.
Power Continuity Server Room Central UPS + Generator line Maintains continuous portal uptime during grid power interruptions.
2 Network, Domain & Firewall Configuration
Configuration Item Target Setting IT Cell Action Required
Subdomain Mapping events.vvce.ac.in (or hub.vvce.ac.in) Add DNS A Record pointing to the server's static public IP.
Network IP 1 Static Public IPv4 Address Enables access both inside campus Wi-Fi and for students at home.
Firewall: Port 80 Inbound Port 80 (HTTP) Enables standard web routing and Let's Encrypt automated SSL setup.
Firewall: Port 443 Inbound Port 443 (HTTPS) Secures student logins and registration forms via SSL/TLS encryption.
Maintenance: Port 22 SSH Port 22 (Restricted) Accessible strictly via campus LAN or authorized administrator IP.
Zero Cloud Expense: The entire software stack (Nginx, PostgreSQL database engine, Docker containerization, and SSL certificates) runs on open-source software on college hardware. No recurring monthly billing or subscription fee to external vendors is required.
